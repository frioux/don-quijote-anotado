# Sources and provenance

All three sources are in the public domain (or CC0) and are stored unmodified in `sources/`.

| File | What | Origin | License |
|---|---|---|---|
| `sources/pg2000.txt` | *Don Quijote* (Parts I and II), Spanish | Project Gutenberg #2000, plain-text UTF-8: <https://www.gutenberg.org/cache/epub/2000/pg2000.txt> | Public domain (Project Gutenberg License applies to the PG header/footer only) |
| `sources/pg996.txt` | *Don Quixote*, John Ormsby's 1885 English translation | Project Gutenberg #996, plain-text UTF-8: <https://www.gutenberg.org/cache/epub/996/pg996.txt> | Public domain |
| `sources/se-chapter-1-1.xhtml` | Ormsby, Part I Ch. 1, with note references | Standard Ebooks source repo: <https://github.com/standardebooks/miguel-de-cervantes-saavedra_don-quixote_john-ormsby> (`src/epub/text/chapter-1-1.xhtml`) | CC0 1.0 |
| `sources/se-endnotes.xhtml` | Ormsby's ~1,000 translator footnotes, transcribed | Same Standard Ebooks repo (`src/epub/text/endnotes.xhtml`) | CC0 1.0 |

Everything else in this repo (literal glosses, vocabulary, summaries, context
commentary, build tooling) was written for this project.

The Spanish text in PG #2000 uses lightly modernized spelling but keeps
Cervantes' archaic forms (`mesmo`, `della`, `fermosura`, `efeto`). They are
kept verbatim and glossed in the vocabulary notes.
